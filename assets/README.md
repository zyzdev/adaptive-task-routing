# Adaptive Task Routing icon

`icon.png` is the shared, user-selected brand asset for all three platform editions.
It was generated using the built-in imagegen tool and retained without modification.
The original PNG is 1254 × 1254 pixels with an alpha channel.

OpenAI supports listing and composer icons. Claude Code and Gemini CLI currently do
not document a custom icon property in their plugin/extension manifests; their
READMEs display this asset instead. Directory cards remain platform-controlled.
