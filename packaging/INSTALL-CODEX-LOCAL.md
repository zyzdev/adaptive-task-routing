# Codex local installation

Use the [OpenAI package installation guide](openai/README.md).
There are exactly three platform ZIPs; no codex-local-marketplace ZIP is produced.
For CLI installation, register the extracted plugin root through a local marketplace,
then use codex plugin add with its confirmed plugin@marketplace selector. For desktop discovery, register that root through
the built-in plugin-creator's local marketplace workflow and start a new task.

Before diagnosing a missing routing result, confirm the actual execution host,
installed plugin path and version, the current task's three-Skill inventory, explicit
invocation, both control modes, and the observed output. Test implicit selection separately.
A missing note alone does not prove a stale window or a failed description match.
Keep shared/ and all three Skill directories together.

繁體中文：請使用 OpenAI ZIP。解壓後保留完整 skills/ 與 shared/；不要把它當成 Marketplace
根目錄匯入。CLI 安裝要使用已確認的 plugin@marketplace；桌面版可透過內建
plugin-creator 建立本機 Marketplace 來源後安裝，並在新任務確認三個 Skills。
排查時依序確認執行主機、安裝路徑與版本、Skill 清單、模式及輸出。
